Writes one original sentence pitching a bizarre startup — trained alpacas rented out as wedding witnesses for $400 a ceremony — that sounds like a joke until the business logic lands: a witness who never objects, never forgets, and looks unforgettable in every photo. Deterministic, model-free Python with no dependencies. The pitch is validated on every run (exactly one line, non-empty, at most 200 characters) and the program refuses to write an invalid line.

## Run it

```sh
python3 main.py
```

Check the pitch without writing anything:

```sh
python3 main.py --verify
```
